# Rejoice Gospel Band Website

A responsive, mobile-friendly website for Rejoice Gospel Band — **Ministering Through Music with Excellence and Passion.**

## Sections
- Home
- About Us
- Our Story
- Services
- Music
- Gallery
- Book Us
- Contact

## Deployment
The repository includes a GitHub Pages workflow in `.github/workflows/pages.yml`. After GitHub Pages is enabled for the repository using **GitHub Actions** as the source, pushes to `main` will deploy the site automatically.
